01 / name
独doku · alone, by oneself
学gaku · learning, study

独学 (dokugaku) is the Japanese word for self-study.

It names exactly what the platform is for: one person, one topic, and the discipline to keep going. The agent teaches, quizzes and grades, but the learning stays yours.

A book, a certification, a tool's documentation, a course: everything you study is a topic, and SLP builds the full loop around it.

02 / why

The method comes built in.

Reading isn't enough: you need someone to explain, quiz you, grade you and make you review right before you forget. SLP takes care of all of that.

Everything stays on your disk.

Notes in Markdown, exams in JSON, attempts and progress next to them. No database, no account. It reads fine on GitHub, in Obsidian or in any editor.

03 / the loop

Prepare, practice, get feedback, review. Each step is a command in your agent, and whatever it produces shows up in the app on its own.

prepareteach · summarize

The agent teaches until it's understood, not memorized, and turns your material into notes.

/slp-teach · /slp-summarize
practiceexams · exercises

Exams you sit in the local app, and applied exercises: code, an ADR, a critique.

/slp-exam · /slp-exercises
feedbackgrade

Every attempt is graded against a rubric, with what you got wrong written down.

/slp-grade
reviewspaced · interleaved

Leitner review across topics so it doesn't fade.

/slp-review · /slp-session

01 / install

uv is the only thing you need to install, plus a coding agent with permission in the repo folder.

1 · install uv
# macOS and Linux
curl -LsSf https://astral.sh/uv/install.sh | sh
# Windows
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
2 · clone
git clone https://github.com/GustavoPenaBeltrami/self-learning-platform.git
cd self-learning-platform
3 · open your agent in the folder and prompt
Read AGENTS.md and run slp-setup.
4 · start the app
uv run slp

// slp-setup exposes the skills in your agent's format and writes only to .git/info/exclude. the first run needs internet; after that it works offline

02 / first topic

Run /slp-init.

The agent asks what it needs and creates the topic. Everything about it lives in one folder, as Markdown and JSON.

topics/example/ is a small one to look at. Your own topics are git-ignored.

topics/<slug>/
├── topic.json      # goals, languages, sources
├── learning.md     # what you know, what you got wrong
├── resources/      # PDFs, slides, transcripts
├── notes/          # summaries and lessons
├── exams/          # exam.json + attempts
├── exercises/
└── progress/       # status.md, log.md

01 / principles

Four Japanese design ideas describe what SLP already does. They are a vocabulary for decisions, not a visual theme.

簡素
kansosimplicity

Remove until only what is needed is left.

// one font, no shadows, no gradients
間
manegative space

Empty space is part of the design, not a gap to fill.

// the ~ buffer, the clear space around the mark
渋い
shibuiquiet beauty

Understated. Nothing is decorated for its own sake.

// hierarchy by lightness, not size
静寂
seijakucalm

The interface stays silent while you study.

// chrome lives in two bars; content stays quiet
02 / logo
Clear space

Keep empty space of at least ¼ of the mark's height on every side. This is ma: the space belongs to the logo.

Minimum size
mark 16px
stacked 96px
horizontal 180px

Below these widths the Latin line stops reading. Use the 独 mark alone.

Don't
  • ✕ add color
  • ✕ stretch or rotate
  • ✕ add shadow or glow
  • ✕ crop or crowd
  • ✕ retype the lettering
