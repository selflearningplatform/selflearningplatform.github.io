# Keyboard shortcuts

Every page with keys has an ⓘ in the top bar: hover it for the list of that page, with your current keys. Action keys can be changed in settings → shortcuts (saved under [shortcuts](settings-json.md) in `settings.json`); `Esc`, bold/italic, the card form save and menu arrows are fixed. The tables show the defaults.

## Notes

| key | action |
| --- | --- |
| `ctrl+m` | start and stop dictation. On macOS too: `⌘M` minimizes the window before the page sees it |
| `⌘B` · `⌘I` | bold, italic (`ctrl` on Windows and Linux). Fixed |
| `Esc` | close menus, previews and an open source. Fixed |
| `⏎` in a mark's comment | close the menu. Fixed |

## Typing

At the start of a line:

| type | becomes |
| --- | --- |
| `/h1` … `/h6` | a heading |
| `/p` | a paragraph |
| `/list` · `/ul` · `- ` · `* ` | a list |
| `/ol` · `1. ` | a numbered list |
| `[[heading]]` | a reference to that section, anywhere in a line |

## Exams

See [exams](exam-app.md). `R` and `T` act on the oral question you are on, or the first one still open.

| key | action |
| --- | --- |
| `⏎` | finish the exam (grade) |
| `R` | record an oral answer, again to stop |
| `T` | answer an oral question in writing |
| `⏎` after grading | retake |
| `Esc` | back to the list. Fixed |

## Exercises

See [exercises](exercises-app.md).

| key | action |
| --- | --- |
| `⌘⏎` | submit the answer |
| `ctrl+i` | attach an image |
| `⏎` after submitting | write again |
| `Esc` | leave the editor, then back to the list. Fixed |

## Cards

See [cards](cards-app.md).

| key | action |
| --- | --- |
| `⏎` | study due (sets, list) · study again (after a session) |
| `A` | study all |
| `C` | new set |
| `N` | new card |
| `L` | list |
| `Space` | reveal the answer |
| `E` · `S` · `D` | edit, skip, delete the current card |
| `1` · `2` · `3` | don't know, knew it, unsure |
| `Esc` | back, or back to the card from the answer. Fixed |
| `⌘⏎` | save the card form. Fixed |

## Menus

`↑` `↓` move through a dropdown, `Esc` closes it.
