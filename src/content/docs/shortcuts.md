# Keyboard shortcuts

Few, and fixed. They are not configurable yet.

## Notes

| key | action |
| --- | --- |
| `ctrl+m` | start and stop dictation. On macOS too: `⌘M` minimizes the window before the page sees it |
| `⌘B` · `⌘I` | bold, italic (`ctrl` on Windows and Linux) |
| `Esc` | close menus and previews |
| `⏎` in a mark's comment | close the menu |

## Typing

At the start of a line:

| type | becomes |
| --- | --- |
| `/h1` … `/h6` | a heading |
| `/p` | a paragraph |
| `/list` · `/ul` · `- ` · `* ` | a list |
| `/ol` · `1. ` | a numbered list |
| `[[heading]]` | a reference to that section, anywhere in a line |

## Exams

| key | action |
| --- | --- |
| `⏎` | grade, or retake after grading |
| `Esc` | back to the list |

## Menus

`↑` `↓` move through a dropdown, `Esc` closes it.
